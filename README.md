# Рыболовный день — версия 7

Добавлены параметры для каждой пойманной рыбы:

- Снасть: Удочка, Спиннинг, Фидер, Донка, Закидушка, Жерлица, Кружки, Нахлыст, Маховая удочка, Болонская удочка, Матчевая удочка, Карповое удилище, Зимняя удочка, Троллинговое удилище.
- Способ ловли: С берега / Лодка.
- Место ловли: Пьяный мост, Мост, Бор, Причал, Груз.Причал, Другое. Для «Другое» появляется поле своего названия.
- Приманка: Хлеб, Мастырка, Червь, Опарыш, Мотыль, Блесна, Макух, Бойл. Можно выбрать несколько приманок одновременно.

Все параметры можно изменить у уже внесённой записи улова. Они выгружаются в Google Таблицу на лист «Улов».

## Обновление

1. На GitHub замените `index.html`.
2. В Google Apps Script замените `Code.gs`.
3. В Apps Script: Развернуть → Управление развертываниями → изменить → Новая версия → Развернуть.
4. URL `/exec` при обновлении существующего развертывания оставьте прежним.
