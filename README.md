# Fishing Day MVP

MVP дневника рыболова.

## Что есть
- автоматическая дата;
- погода из интернета по геолокации через Open-Meteo;
- температура, ощущаемая температура, влажность, давление, осадки;
- направление, скорость и порывы ветра;
- ручной учёт улова;
- выпадающий список видов рыб;
- количество и время поимки;
- локальное сохранение данных в браузере;
- экспорт CSV.

## Как запустить через GitHub Pages
1. Загрузите `index.html`, `.nojekyll` и этот `README.md` в корень репозитория.
2. Откройте GitHub → Settings → Pages.
3. В разделе Build and deployment выберите:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Нажмите Save.

Сайт будет доступен по адресу вида:
`https://<username>.github.io/<repository>/`

> Для автоматической погоды браузер должен дать сайту доступ к геолокации.
