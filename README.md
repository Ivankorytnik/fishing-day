# Рыболовный день — MVP v3

Годовой дневник рыбалки с автоматической погодой и выгрузкой в Google Таблицы.

## Что изменилось

- отдельный признак «Была рыбалка: Да / Нет»;
- рыбалка без улова сохраняется как полноценный рыболовный день;
- годовой журнал показывает каждый день года — 365/366 строк;
- выбор года и просмотр истории по годам;
- годовые показатели: число рыбалок, общий улов, количество видов, лучший день;
- синхронизация всех лет с данными в Google Таблицу;
- Google Таблица автоматически создаёт:
  - `Сводка` — итог по годам;
  - `2026`, `2027`, ... — все дни соответствующего года;
  - `Улов` — детализация каждой поимки.

## Файлы

- `index.html` — сайт для GitHub Pages.
- `Code.gs` — обработчик для Google Apps Script.
- `.nojekyll` — файл для GitHub Pages.

## 1. Обновление сайта на GitHub

Загрузите `index.html` и `.nojekyll` в корень репозитория `fishing-day`, заменив старый `index.html`.

Для GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## 2. Настройка Google Таблицы

1. Создайте новую Google Таблицу.
2. В таблице откройте **Расширения → Apps Script**.
3. Удалите стандартный код и вставьте содержимое `Code.gs`.
4. Нажмите **Deploy → New deployment**.
5. Тип: **Web app**.
6. **Execute as:** Me.
7. **Who has access:** Anyone.
8. Нажмите Deploy и подтвердите разрешения.
9. Скопируйте URL веб-приложения, заканчивающийся на `/exec`.
10. Откройте сайт «Рыболовный день».
11. В блоке **Google Таблица** вставьте этот URL.
12. Нажмите **Сохранить URL**, затем **Выгрузить все годы**.

После синхронизации в Google Таблице появятся вкладки `Сводка`, годовые вкладки и `Улов`.

## Важно

Данные дневника хранятся в `localStorage` браузера, а Google Таблица используется как централизованный архив/выгрузка. Если открыть сайт на другом устройстве, локальная история автоматически оттуда не загрузится обратно в сайт — текущая версия синхронизации работает в направлении **сайт → Google Таблица**.
