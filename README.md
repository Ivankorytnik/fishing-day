# Рыболовный день


## Версия 32 - рабочая оптимизация интерфейса

Главный сценарий перестроен вокруг работы перед рыбалкой:
1. Выбрать день.
2. Выбрать конкретный вид рыбы.
3. Сразу увидеть индекс дня, лучший час, лучшее окно и 5 лучших часов.
4. Проверить условия и давление 12/24/72 часа.
5. Записать факт рыбалки, комментарий и улов.

Изменения:
- прогноз по конкретному виду рыбы вынесен в главный рабочий блок;
- вид рыбы выбирается из выпадающего списка;
- выбор рыбы запоминается в браузере;
- динамический заголовок `Прогноз клёва: Карась / Лещ / ...`;
- показан температурный профиль модели для выбранного вида;
- добавлены 5 лучших часов дня для выбранной рыбы;
- подробная почасовая таблица сворачивается, чтобы не перегружать экран;
- добавлена быстрая навигация: прогноз, улов, результат дня, журнал;
- интерфейс стал компактнее, без большой шапки;
- данные дневника и Google-синхронизация сохранены;
- давление 12/24/72 часа сохранено без изменения логики.


## Версия 33 — полная перекалибровка прогноза клёва

Предыдущая модель завышала прогноз: база была 45 баллов, а температура, стабильное давление,
ветер, облачность и рассвет складывались как крупные бонусы. В обычный хороший час сумма легко
превышала 100 и обрезалась до 95.

Новая модель:
- база по видам снижена до 16–24;
- добавлена сезонность каждого вида по месяцам;
- используется температурный фон за 48 часов, а не температура воздуха одного часа;
- давление 12/24/72 часа сохранено для анализа, но имеет небольшой вес;
- для щуки и окуня прямой вес давления снижен дополнительно;
- обычный ветер и облачность дают маленькие бонусы;
- сильный ветер, ливень, гроза и плохой температурный фон дают большие штрафы и ограничивают максимум;
- высокий индекс возможен только при совпадении нескольких сильных факторов;
- фактические рыбалки из дневника калибруют прогноз;
- серия пустых выездов снижает прогноз;
- максимальный индекс ограничен 88;
- результат показывается как индекс `/100`, а не как статистическая вероятность.

Шкала:
- 80–88: исключительный;
- 65–79: высокий;
- 50–64: выше среднего;
- 35–49: средний;
- 20–34: слабый;
- ниже 20: низкий.


## Версия 34 - прогноз, который учится на факте

Добавлено:
- целевая рыба для каждой рыбалки, включая нулевой улов;
- время начала и окончания рыбалки;
- CPUE: количество пойманной рыбы на час ловли;
- ручной замер температуры воды и расчётная оценка по 7-дневному погодному фону;
- ручной тренд уровня/течения воды;
- GloFAS river discharge как слабый автоматический прокси водного режима;
- фильтры прогноза по месту, снасти и приманке;
- калибровка по похожим фактическим рыбалкам;
- осадки за 6/24/72 часа;
- солнечная радиация и продолжительность солнечного света;
- фаза Луны с очень небольшим весом для ночных видов;
- сохранение прогноза перед рыбалкой и последующее сравнение с фактом;
- обратная коррекция модели, если прошлые высокие прогнозы не подтверждались;
- уровень уверенности модели по объёму личной статистики;
- CSV расширен параметрами сессии, воды и CPUE.

Google Apps Script не менялся: новые поля работают в браузере и CSV, старый формат синхронизации Google Sheets остаётся совместимым.


## Версия 35 - минималистичный рабочий интерфейс

Функциональность и формула прогноза версии 34 сохранены. Изменён только интерфейс:
- компактная шапка и навигация;
- дата вынесена в короткую рабочую строку;
- прогноз стал главным блоком;
- почасовая таблица по умолчанию свёрнута;
- методика расчёта спрятана в отдельный раскрываемый блок;
- условия дня и факт рыбалки собраны рядом на широком экране;
- комментарий и Google-синхронизация сворачиваются;
- убраны тени, лишние цветные подложки и крупные скругления;
- журнал снова имеет нормальный читаемый шрифт и при необходимости горизонтальную прокрутку на узких экранах.
