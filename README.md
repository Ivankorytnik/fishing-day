# Рыболовный день — v5

Добавлен комментарий к каждому календарному дню.

## Что нового
- комментарий редактируется для выбранной даты;
- комментарий сохраняется в браузере вместе с данными дня;
- комментарий виден в годовом журнале;
- комментарий включён в CSV;
- комментарий выгружается в годовые вкладки Google Таблицы отдельным столбцом `Комментарий`.

## Обновление GitHub Pages
Замените `index.html` в корне репозитория новым файлом.

## Обновление Google Apps Script
Так как структура выгрузки изменилась, замените старый `Code.gs` новым файлом из комплекта. Затем: **Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть**.

Существующий URL `/exec` можно оставить, если обновляете текущее развертывание.
